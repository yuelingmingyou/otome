# 🎀 Otome Memory

一个专为乙女游戏玩家设计的个人游戏记录网站，可以记录玩过的乙女游戏信息、评分和感想，支持数据导入导出和本地持久化存储。

![预览](https://your-screenshot-url-here.png)

## ✨ 功能特色

| 功能 | 说明 |
|:---|:---|
| 🎀 蕾丝蝴蝶结主题 | 粉色系可爱界面，CSS 实现蕾丝边框和蝴蝶结装饰 |
| 📝 游戏信息记录 | 游戏名、画师、剧本、声优、发售信息、游玩时间等 |

| 📅 发售日期标签 | 支持多平台多版本发售记录（如 2011年：PSP版 / 2019年：Vita版） |

| 💾 本地存储 | 自动保存到浏览器 localStorage，刷新不丢失 |
| 📤📥 导入导出 | JSON 格式备份和恢复数据 |
| 📱 响应式设计 | 适配桌面端和移动端 |

## 🚀 快速开始

### 方法一：GitHub Pages 部署（推荐）

1. **Fork 或创建仓库**
   - 创建 GitHub 仓库，例如 `yourname.github.io/otome/`

2. **上传文件**
3. **开启 GitHub Pages**
- Settings → Pages → Source → Deploy from a branch
- 选择 `main` 分支，`/(root)` 目录
- 等待几分钟，访问 `https://yourname.github.io/otome/`

> ⚠️ **重要**：必须创建 `.nojekyll` 空文件，否则 GitHub Pages 会用 Jekyll 处理导致页面空白！

### 方法二：本地直接使用

直接用浏览器打开 `index.html` 即可使用，无需服务器。

> 注意：本地使用时导入导出功能正常，但数据仅在当前浏览器会话中保存。

## 📖 使用指南

### 添加游戏

1. 点击右上角 **"＋ 添加游戏"** 按钮
2. **上传封面图**：点击上传区域选择本地图片
3. **填写基本信息**：
- 游戏名（必填）
- 画师、剧本
- 发售/开发公司
- 游玩时间
4. **添加声优**（可选）：
- 输入格式：`角色名（声优名）`
- 例如：`蒼（神奈延年）`
- 按 **回车** 或点击 **＋** 按钮添加
- 点击标签上的 **×** 删除
5. **添加发售时间**（可选）：
- 输入格式：`YYYY年M月D日：平台版`
- 例如：`2011年7月28日：PSP版`
- 支持添加多个版本（PSP、Vita、Switch等）
6. **评分**：点击星星
- **左半部分** = 半星（如 3.5）
- **右半部分** = 整星（如 4）
7. **感想**：填写个人评价
8. 点击 **"保存"**

### 查看详情

- 首页点击任意游戏卡片，弹出详情页
- 显示完整信息、声优列表、发售版本、评分和感想

### 编辑游戏

- 在详情页点击底部 **"✏️ 编辑"** 按钮
- 所有信息（包括图片、标签、评分）都会完整恢复
- 修改后保存即可

### 删除游戏

- 详情页点击 **"🗑️ 删除"** 按钮
- 确认后永久删除（可重新导入恢复）

### 搜索筛选

- 顶部搜索框输入关键词
- 支持搜索：**游戏名、剧本、画师、声优名**
- 实时过滤显示结果

### 数据备份

#### 导出数据
1. 点击 **"📤 导出"** 按钮
2. 自动下载 `otome-collection-YYYY-MM-DD.json` 文件
3. 包含所有游戏记录和图片（Base64编码）

#### 导入数据
1. 点击 **"📥 导入"** 按钮
2. 选择之前导出的 `.json` 文件
3. 确认覆盖当前数据
4. 导入成功后会自动刷新显示

> 💡 **建议**：定期导出备份，换设备或浏览器时迁移数据

导出的 JSON 文件结构：

```json

"version": "1.1",

"games": [
 {
   "id": "唯一标识符",
   "title": "游戏名",
   "artist": "画师",
   "writer": "剧本",
   "voiceActors": "[{\"char\":\"角色名\",\"seiyuu\":\"声优名\"}]",
   "developer": "发售/开发",
   "releaseDate": "[\"2011年7月28日：PSP版\",\"2019年7月25日：Vita版\"]",
   "playTime": "游玩时间",
   "rating": 4.5,
   "review": "感想内容",
   "image": "data:image/jpeg;base64,..."  // 封面图Base64
 }
]
}
